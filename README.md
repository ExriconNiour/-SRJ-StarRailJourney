# [SRJ] StarRailJourney

A Minecraft Forge mod based on *Honkai: Star Rail*.

## Features
- **Player Attributes**: Press **C** to view your stats.
- **8 Combat Debuffs**: Shock, Burn, Wind Shear, Laceration, Imprison, Entanglement, Freeze, and Vulnerability.
- **4 Types of Curios**: Paths, Light Cones, Tunnel Instruments, and Planar Ornaments.
- **Custom Systems**: Slot unlockers, materials, and stonecutter recipes.

## Requirements
- Minecraft 1.20.1
- Forge
- **Curios API** (Required dependency)
